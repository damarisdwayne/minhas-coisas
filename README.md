# Minhas Coisas

Site pessoal com minhas listas: indicações de profissionais (e, em breve, lojas e livros).

```bash
yarn
yarn dev   # http://localhost:3001
```

Copie `.env.example` para `.env.local` e preencha as chaves do Firebase. O login é pelo Google.

Para carregar a lista inicial de profissionais, entre no site e use **Importar lista** com o arquivo `dados/indicacoes-palmares.json`.
